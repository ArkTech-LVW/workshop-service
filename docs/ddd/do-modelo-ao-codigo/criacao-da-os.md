# Criação da OS

Aba **ES - Criação da OS** do [`workshop-ddd.drawio`](../workshop-ddd.drawio): do cliente chegando na oficina até o orçamento enviado para aprovação. As colunas e as marcações estão explicadas em [Como ler as tabelas](README.md#como-ler-as-tabelas).

| Cadastra veículo | Comando | [`POST /admin/vehicles`](../../../src/main/java/br/com/arktech/workshop/registry/api/vehicle/IVehicleController.java) → [`CreateVehicleUseCase`](../../../src/main/java/br/com/arktech/workshop/registry/application/createvehicle/CreateVehicleUseCase.java) | A abertura da OS também cadastra o veículo quando a placa é nova: [`RegistryVehicleDirectory.findOrRegister`](../../../src/main/java/br/com/arktech/workshop/registry/application/vehicle/RegistryVehicleDirectory.java). |
| Abre OS | Comando | [`POST /admin/serviceOrders`](../../../src/main/java/br/com/arktech/workshop/serviceorder/api/serviceorder/IServiceOrderController.java) → [`OpenServiceOrderUseCase`](../../../src/main/java/br/com/arktech/workshop/serviceorder/application/openserviceorder/OpenServiceOrderUseCase.java) | |

| Inclui peça ou insumo | Comando | [`POST /admin/serviceOrders/{id}/parts`](../../../src/main/java/br/com/arktech/workshop/serviceorder/api/serviceorderitem/IServiceOrderItemController.java) → [`AddPartItemUseCase`](../../../src/main/java/br/com/arktech/workshop/serviceorder/application/addpartitem/AddPartItemUseCase.java) | |
